# Architect Studio

A simple freelance portfolio/landing page for an architecture firm, built with Django and custom frontend templates.

## Overview
This project is a frontend showcase website for an architectural company. It includes multiple pages such as Home, About, Services, Projects, Team, and Contact, with a clean and modern design.

## Tech Stack
- Python
- Django
- HTML
- CSS
- JavaScript

## Features
- Modern homepage layout
- About section
- Services section
- Projects showcase
- Team profile section
- Contact page
- Responsive design for desktop and mobile screens

## Project Structure
- `home/` – main app with views and page routes
- `templates/` – HTML templates for the site
- `static/` – CSS and JavaScript files
- `architect/` – Django project configuration

## Run Locally
1. Open a terminal in the project folder.
2. Activate the virtual environment:
   ```bash
   env\Scripts\activate
   ```
3. Start the server:
   ```bash
   python manage.py runserver
   ```
4. Open the website in your browser at:
   ```bash
   http://127.0.0.1:8000/
   ```

## Notes
This is a frontend-focused freelance project intended for portfolio and GitHub showcase purposes. The current implementation focuses on design and page structure rather than backend-heavy functionality.
